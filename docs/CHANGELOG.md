## 2026-11-23 — 直接计算几何特征与剖面序列

- 新增 `backend/features.py`，使用当前保留的完整毫米点云计算可见几何向量 G、拟合中心线和沿局部法向的定长剖面 T；默认 K=32，也支持 16/64，包含宽度、高度/相对高度、梯度、横剖面形状和质量通道。
- 在原“测量复核”侧栏增加计算、曲线、剖面预览、原图定位及独立标记，保留三步导航和原直线切片功能。复核条件、参数与标记可暂存恢复，绑定坐标参考和清理摘要，变化时失效；不复用旧切片确认。
- 支持当前 JSON/CSV/NPZ 下载和整批导出：每条已对齐采集生成 `geometry_features.json`、`profile_sequence.csv/npz`，根目录生成 `geometry_features.csv`。未对齐采集留空，真实体重列留空；记录相机、模态、哈希、参数及质量条件。
- 明确数字可算、候选可用和人工复核三类掩码；端点截断或中心线缺支撑时禁止当完整定长输入，未复核地面时地面高度与积分缺失。面积不补洞、积分不当整猪体积、可见跨度不当胸围；不改原始图像、掩码、点坐标或主点云选择规则。
- 补充 [特征计算说明](features.md)，同步首页、使用手册、架构、文件职责及开发说明；参考用户两份方案，未采用未经验证的精度承诺或固定相机内参。
- 验证：112 项 Python 测试、34 项前端测试、三个 JS 语法检查和差异格式检查通过；已验证已知直体/弯体尺寸、尺度、空洞、掩码、保存回滚、版本失效、无清理记录和清理后导出、未对齐批表及 HTTP 权限。临时合成数据浏览器验证参数保存/恢复、独立标记、三种下载、原切片、720px 窗口和离线只读剖面预览；两条真实已对齐 iToF 采集只读试算均为 32/32 可算，单条约 0.08–0.13 秒。重启工作台加载新接口，现有 357 条采集、2 条对齐记录与设置文件哈希保持一致；真实页面只读验收通过。尚未用真实体重标签验证预测价值。
