# 几何特征与剖面序列

实现日期：2026-11-23；2026-11-24 增加可见横剖面弧长，算法标识更新为 `visible-surface-features-v2`。这是供后续体重估测试验使用的候选输入提取器，尚未通过实测体尺或体重标签标定。

## 使用步骤

1. 保守清理飞点，确认地面、尾根和**颈躯连接点**，完成坐标对齐。
2. 打开“测量复核 → 几何特征与剖面序列”。页面自动用当前保留的完整点云计算候选值；自动计算不写处理记录。
3. 默认 K=32、薄带厚度 20 mm、最少 20 点、面积网格 10 mm。可选 K=16/32/64；修改后点“计算并保存参数”。这些是初始试验参数，不是已验证的最佳组合。
4. 端点与地面直接沿用已确认的坐标对齐，默认可用，不再另外选择参考条件。低头时仍用颈躯连接点；头部不可见本身不等于躯干端点不可见。参考不适用时，可返回对齐修正，或在顶部阶段筛选中淘汰本采集。
5. 点击序列曲线、滑块或箭头查看剖面。橙色点、剖面图、原图定位对应当前局部法向薄带；蓝线的 XY 路径参与弧长和剖面计算，两端连接已确认的尾根、颈根。三维显示的高度在这两点之间线性插值，供核对连接位置，不是实测背脊线，也不参与 XY 弧长计算。
6. 在序列曲线上拖选区域，或输入起止剖面编号，再点“确认所选／淘汰所选／恢复待定”；“全部剖面”可一次选择全部。范围包含起止两片，切换当前片不改变选区。批量确认跳过点数或中心线支撑不足的剖面，并提示跳过数量；其原状态保留。也可逐剖面标记“边界完整·可测 / 缺失·不可测 / 待定”。点多仍可能只看到身体一侧，须结合原图判断。左侧进度与这些确认记录一致；旧直线切片入口已移除。

   “确认所选”只修改当前范围。复核结束后点击工作台顶部测量筛选的“保留”，当前版本所有仍待定的剖面自动标为不可测，已经确认可测或不可测的剖面保持不变。例如确认第 1–31 片后保留测量阶段，第 32 片自动淘汰，显示 31/32 片可测、淘汰 1、待定 0。区域确认可分多次进行；最终处理依据累计保存的逐片状态，而非最后一次选区。之后仍可重新确认或恢复待定，修改后需重新保留测量阶段。此操作不删除点，也不改变端点、弧长或整段测量范围。
7. 顶部“导出点云成果”勾选“测量复核”，即可统一保存已保存参数或逐片复核的测量成果：每条整体几何 JSON、剖面序列 CSV/NPZ 和测量汇总，以及根目录批量几何 CSV。全部 13 项整体指标、10 个序列通道和对应有效性／复核标记一同保存，部分复核也可导出。未开始测量的采集不会自动生成测量阶段。

桌面测量面板上方整行放参数和计算按钮，中间并列序列曲线和当前剖面，紧接区域批量复核工具，下方整行展示全部几何指标；三个单独下载按钮已移除，统一从顶部导出。短窗口自动压缩图高；窄面板将两张图上下排列，指标改为两列，小屏上下排列点云和面板。说明文字在“测量说明与导出”中展开。序列曲线下拉框可查看全部 10 个通道；绿色点为可测，黄色点为待定，红色点为不可测，选区带底色。

参数和标记沿用现有处理缓存，保存后可恢复。更换参数、删点/恢复点或改变坐标参考会重置局部剖面标记；端点与地面始终取当前已确认对齐。旧参考条件选项不再覆盖该默认值，也不会单独重置已有标记；读取历史记录不改写文件。原始图像、分割和原始点云不改写。

测量阶段保留与“所有剖面均可测”分开记录。存在淘汰剖面时，阶段仍可保留并完成采集筛选，但 `measurement_ready` 不会变为真。导出的 JSON/CSV 保留每片状态，NPZ 保留全部 K 行，淘汰片的 `usable_mask`、`reviewed_mask` 均为假，不删除行或把候选数值伪装成确认值。旧记录载入不自动改写；对历史部分复核再次点击测量阶段“保留”才应用本规则。

## 中心线与计算范围

输入是原始 `points.npz` 中当前保留的全部点，经已确认刚性矩阵转成毫米猪体坐标；仅取 `0 ≤ X ≤ 端点投影距离` 的区间。显示抽样不参与数值计算。不做单位球缩放、点坐标平滑、补洞或隐藏体表推断。

X 方向划分 16–64 个种子带（约每 30 mm 一带，数量与 K 独立）。每带达到最少点数时，以 Y 的 Q02 与 Q98 中点作为可见中线种子。猪体坐标中尾根、颈根的地面投影分别为 `(0,0)`、`(L,0)`；用这两个端点作为硬约束，对整段有效种子作一次三次平滑样条拟合，不在旧曲线两端另接短过渡段。计算 257 个参考节点及 XY 折线弧长，再用同一曲线计算等弧长站位、局部切向和剖面。

令 `t=X/L`，样条内部结点位于 0.25、0.5、0.75。基函数取 `t²−t`、`t³−t`、`max(t−k,0)³−t(1−k)³`，因此每个基函数在 0 和 1 都为零，拟合曲线直接通过两端点。目标为种子残差均方加 `0.001×二阶导数均方`，后项在 257 个等距归一化位置计算。种子带等权，不随点密度增加权重；曲率惩罚抑制局部抖动，曲线在内部结点处保持二阶连续。该平滑系数为当前可追溯的试验参数，尚未用实测中线标定。

整段拟合方法标记为 `endpoint-constrained-smoothing-spline-v1`，不改变 v2 的十个序列通道。JSON 的 `centerline.version`、工作台计算来源 `provenance.centerline_version`、CSV/NPZ 的 `centerline_version` 均记录使用的方法。存在历史可测/不可测剖面标记的记录，继续沿用 `local-smoothed-mid-envelope-v1` 或端部过渡版 `endpoint-constrained-mid-envelope-v1` 及原复核结果，页面提示其为历史中心线；点击「计算并保存参数」即改用新曲线并将本条剖面复核回到待定。尚无可测/不可测标记，或重新标定并确认端点/地面后，采用整段拟合方法。读取、查看和导出历史记录不会自行改写其确认结论。

空种子带保留为缺支撑；画出的参考曲线不表示缺口已修复。中心线是可见包络的中线，偏侧遮挡会让它偏移。当前模型为 `Y=f(X)`，不能处理身体折返、明显 U 形、叠猪或严重侧弯；这类采集应回到采集筛选或标记不可测，不能解释为已恢复姿态。

K 个站位包含区间两端，沿拟合弧长等距排列。每站取水平切向 `t`、横向法向 `n=(-t_y,t_x)`，选 `|t·(XY-c)| ≤ 厚度/2` 的点，并限制 `|X-c_x| ≤ 投影距离×0.2`，避免远处体段再次穿过同一平面。剖面坐标为 `u=n·(XY-c)` 与 Z。端部只取区间内的点，支撑点数可能较少；相邻薄带允许重叠，不能把各片点数当独立样本相加。

## 几何向量 G

每项记录 `{value, unit, valid, reviewed}`，保留实际单位。

| 字段 | 定义与限制 |
| --- | --- |
| `endpoint_ground_chord_mm` | 尾根到颈躯连接点的地面平面投影距离，不是标准解剖体长；端点截断/不明时缺失 |
| `visible_centerline_arc_mm` | 连接尾根、颈根地面投影的端点约束中心线 XY 弧长，不是沿背部三维表面的长度；历史算法的端点仅限定 X 区间；中心线缺支撑或端点截断时缺失 |
| `centerline_arc_chord_ratio` | 上述弧长/投影距离，作为弯曲姿态代理 |
| `profile_width_median_mm / max_mm / p90_mm` | 可算且未标记不可测的 K 剖面宽度统计；缺失时只汇总已有剖面，须同时读取可算数量 |
| `width_25pct_mm / 50pct_mm / 75pct_mm` | 另取精确弧长 25/50/75% 局部法向薄带独立算宽度，不是最近 K 站位或宽度插值；路径不可靠时缺失。始终是候选值，邻近剖面的确认不确认这些额外平面 |
| `visible_height_p95_mm` | 整个保留区间 Z 的 P95；仅在地面参考已复核时输出 |
| `relative_height_p95_p05_mm` | 区间全体 Z 的 P95−P05，不依赖地面平移，但不是猪的实际高度 |
| `observed_grid_area_mm2` | `floor(X/grid),floor(Y/grid)` 有点网格数×网格面积；洞不填充，数值依赖网格分辨率 |
| `observed_positive_height_integral_mm3` | 每个有点 XY 格取 Z 中位数，负值截为 0，再乘格面积求和；需复核地面。这是可见高度积分代理，不能当整猪体积 |

宽度为 `Q98(u)−Q02(u)`，减轻少量极端点影响；每片另存 `width_raw_span_mm=max(u)−min(u)` 作对照。它会受采样密度、遮挡、体侧缺失和残余飞点影响，不是真实完整体宽、胸围或横截面积；分位数不替代飞点清理。

端点完整、路径有支撑且全部 K 片可测时，宽度统计的 `reviewed` 才为真；长度需确认对齐提供的端点且相关数值可算。地面高度的 `reviewed` 表示采用已确认对齐的地面参考，不代表每片边界已确认。面积和积分仍作为候选代理，没有自动验收整个体表的机制。

## 固定剖面序列 T

默认 `values.shape=(32,10)`，通道名与单位写入 NPZ。新增弧长通道追加到原 9 个通道末尾，原通道顺序不变；读取时应按 `channel_names` 匹配，不能写死列数。历史导出保持原样，重新计算或导出才得到 v2 数据；原清理、坐标和边界复核记录继续保留。

| 通道 | 定义 | 单位 |
| --- | --- | --- |
| `width_q02_q98_mm` | 局部可见横向稳健跨度 | mm |
| `height_p95_mm` | 本片 Z 的 P95，需地面复核 | mm |
| `relative_height_p95_mm` | 本片 Z 的 P95 减整个区间 Z 的 P05 | mm |
| `height_gradient` | 相邻两侧高度差/弧长差，端部单侧差分；自身或邻片缺高程、被拒绝时缺失 | mm/mm |
| `transverse_curvature_per_mm` | 横向网格中位数二次拟合的中心带符号曲率，不是整猪解剖曲率 | 1/mm |
| `bulge_mm` | 拟合中心高度减两端拟合高度均值，凸起为正 | mm |
| `point_count` | 薄带实际保留点数，0 可以是真实空带计数 | count |
| `transverse_bin_coverage` | 12 个横向小格中至少含 2 点的格子比例，不是体表可见率或边界完整概率 | ratio |
| `fit_rmse_mm` | 二次曲线对有效横向格中位数的 RMSE，小误差不证明边界完整 | mm |
| `visible_transverse_arc_mm` | 本片可见横向轮廓的分箱中位数折线长度，不是中心线弧长或完整围度 | mm |

二次拟合仅在稳健宽度至少 40 mm、12 格中至少 6 格各有 2 点，且有效格横向覆盖至少稳健宽度 70% 时输出。设 `v=(u−宽度中点)/宽度`，拟合 `z=a v²+b v+c`：中心曲率为 `(2a/宽度²)/(1+(b/宽度)²)^(3/2)`，凸起为 `−a/4`。这些是当前可检验的实现定义，不宣称文献已验证了本实现参数。

可见横剖面弧长独立于二次拟合计算：在当前薄带横向坐标 P02–P98 内等宽分箱，箱数 `clip(ceil(宽度/5 mm), 2, 256)`。每箱至少 2 点，取 `(u,Z)` 中位数作节点，累计相邻节点的欧氏距离。宽度不足 10 mm、任一箱缺点/少于 2 点，或相邻节点高度跳变超过 `max(20 mm, 4×横向节点距离)` 时，该通道缺失；不会跨过缺箱连接或将端点外推到宽度边缘。首尾节点是首尾箱中位数，因此弧长与 P02–P98 宽度的端点略有不同，不能强制要求弧长大于该宽度。

这是有限厚度薄带中可见表面的稳健离散弧长代理；分箱会减少细节，也不能自动判定多层遮挡或真实边界完整性。5 mm、每箱 2 点和跳变阈值是当前可追溯的试验规则，尚未标定，不是论文统一标准。它不补全猪腹、不能当胸围；地面平移不影响本通道。每片另存 `visible_transverse_arc_missing_reason` 与 `visible_transverse_arc_bin_count`，分别记录缺失原因和分箱数；质量汇总 `computable_transverse_arcs` 记录可算且未拒绝的片数。宽度可算时弧长仍可能缺失，使用其自身掩码判断。页面同时显示当前片的宽度、横剖面弧长及缺失原因。

## 缺失与复核掩码

JSON 用 `null`，CSV 用空单元格，NPZ 用 `NaN`，不会把缺宽度、缺高度填成实测零。三个同形布尔矩阵：

- `valid_mask`：该通道数值可算；`point_count=0` 可以是真实计数，但形状通道可能缺失。
- `usable_mask`：数值可算、站位有中心线支撑、剖面未拒绝，且整个中心线路径支持定长站位、端点未标记截断。待定剖面可能为真，不能当人工确认。
- `reviewed_mask`：在 usable 基础上，当前剖面已确认可测且两端已确认完整。工作台的端点、地面条件沿用已确认对齐，剖面边界仍需逐片或批量确认。

中心线有缺口时可保留局部诊断候选，但定长序列的 `usable_mask` 全为假；参考曲线 0–100% 不代表可靠完整体段。工作台默认 `conditions={endpoints: complete, ground: reliable}`，来源写入 `provenance.reference_conditions_source=confirmed_alignment_default`；这不会填补缺点或自动确认剖面。独立数学接口仍支持未知或截断参考条件，截断时禁止把部分躯干伸缩成完整输入。`sequence_position_valid` 表示路径有支撑。

每片另存 status、missing_reason、centerline_supported、中心 XY、切向、弧长与比例。点数、覆盖率、拟合误差只作质量代理，不生成虚构置信度，也不把 IR 灰度当幅值/深度置信度。

## 导出与后续使用

| 文件 | 内容 |
| --- | --- |
| 每条 `geometry_features.json` | G、剖面列表、精确分位平面、定义、中心线支撑、参数、条件、警告、输入哈希和坐标参考 |
| 每条 `profile_sequence.csv` | K 行及各通道 valid/usable/reviewed 列 |
| 每条 `profile_sequence.npz` | values、三种掩码、channel_names、channel_units、fraction、arc_position_mm、schema_version；可 `allow_pickle=False` 读取 |
| 根目录 `geometry_features.csv` | 按猪号、采集、模态、相机列出 G、掩码、质量统计、参数、输入版本；未对齐行标 `unaligned` 并留空特征 |

导出用同一模块重新计算，绑定原点云/生成记录哈希、清理摘要和已确认坐标参考；不会导出显示采样的测量值。不强制创建删点操作；保存测量参数、逐片或批量标记后即可随测量阶段统一导出。JSON 中几何值保留原始单位（mm、mm²、mm³、比例），批量 CSV 使用字段名标明单位；界面显示的 m² 和 L 仅为换算展示。`has_features` 只说明导出了文件；`measurement_ready` 统一表示当前局部法向剖面全部确认为可测、使用已确认对齐的端点且中心线有完整支撑；各通道的有效性仍分别记录。旧直线切片确认不计入当前进度。

面积、全局高度和积分统计整个保留区间；标记剖面不可测不等于删除点，只有宽度序列汇总跳过该片。如污染影响全局特征，应回到清理或采集筛选。

后续须关联真实称重表；批量表的 `weight_kg` 留空、`weight_status=not_provided`，不虚构标签。按猪个体拆分训练/验证，核对称重与采集时刻，避免同猪不同帧泄漏。iToF 与双目先分别验证；K、厚度、网格应一致或作为明确试验变量。预测价值和特征取舍需真实体重交叉验证，本功能只负责可追溯输入提取。
