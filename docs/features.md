# 几何特征与剖面序列

实现日期：2026-11-23。算法标识：`visible-surface-features-v1`。这是供后续体重估测试验使用的候选输入提取器，尚未通过实测体尺或体重标签标定。

## 使用步骤

1. 保守清理飞点，确认地面、尾根和**颈躯连接点**，完成坐标对齐。
2. 打开“测量复核 → 几何特征与剖面序列”。页面自动用当前保留的完整点云计算候选值；自动计算不写处理记录。
3. 默认 K=32、薄带厚度 20 mm、最少 20 点、面积网格 10 mm。可选 K=16/32/64；修改后点“计算并保存参数”。这些是初始试验参数，不是已验证的最佳组合。
4. 复核两端标注完整性。低头时仍用颈躯连接点；头部不可见本身不等于躯干端点不可见。端点不明或躯干被截断，选择“有截断或端点不明”。地面拟合与方向可靠时，才选“已复核地面，高度可用”。
5. 点击序列曲线、滑块或箭头查看剖面。橙色点、剖面图、原图定位对应当前局部法向薄带；蓝线只示意 XY 中心线走向，为便于看清显示在主体中高平面，不是实测背脊线。
6. 逐剖面标记“边界完整·可测 / 缺失·不可测 / 待定”。点多仍可能只看到身体一侧，须结合原图判断。原直线切片保留在下方折叠区，确认状态各自独立。
7. 可下载几何 JSON、序列 CSV/NPZ；顶部“导出点云成果”自动计算导出范围内所有已对齐采集，不必逐条点击。未保存本面板参数的采集使用默认参数和待复核条件。

参数、复核条件和标记沿用现有处理缓存，保存后可恢复。更换参数或复核条件会重置局部剖面标记；删点/恢复点后，剖面标记、端点与地面可靠性条件重置；坐标参考变化后旧标记和条件失效。原始图像、分割和原始点云不改写。

## 中心线与计算范围

输入是原始 `points.npz` 中当前保留的全部点，经已确认刚性矩阵转成毫米猪体坐标；仅取 `0 ≤ X ≤ 端点投影距离` 的区间。显示抽样不参与数值计算。不做单位球缩放、点坐标平滑、补洞或隐藏体表推断。

X 方向划分 16–64 个种子带（约每 30 mm 一带，数量与 K 独立）。每带达到最少点数时，以 Y 的 Q02 与 Q98 中点作为可见中线种子；用相邻最多五个连续有效种子的局部线性拟合平滑，再作分段线性插值。端部最多半个种子带作斜率延伸。计算 257 个参考节点及折线弧长。

空种子带保留为缺支撑；画出的参考曲线不表示缺口已修复。中心线是可见包络的中线，偏侧遮挡会让它偏移。当前模型为 `Y=f(X)`，不能处理身体折返、明显 U 形、叠猪或严重侧弯；这类采集应回到采集筛选或标记不可测，不能解释为已恢复姿态。

K 个站位包含区间两端，沿拟合弧长等距排列。每站取水平切向 `t`、横向法向 `n=(-t_y,t_x)`，选 `|t·(XY-c)| ≤ 厚度/2` 的点，并限制 `|X-c_x| ≤ 投影距离×0.2`，避免远处体段再次穿过同一平面。剖面坐标为 `u=n·(XY-c)` 与 Z。端部只取区间内的点，支撑点数可能较少；相邻薄带允许重叠，不能把各片点数当独立样本相加。

## 几何向量 G

每项记录 `{value, unit, valid, reviewed}`，保留实际单位。

| 字段 | 定义与限制 |
| --- | --- |
| `endpoint_ground_chord_mm` | 尾根到颈躯连接点的地面平面投影距离，不是标准解剖体长；端点截断/不明时缺失 |
| `visible_centerline_arc_mm` | 两个端点 X 平面之间可见中线的 XY 弧长，不是沿背部三维表面的长度；中心线缺支撑或端点截断时缺失 |
| `centerline_arc_chord_ratio` | 上述弧长/投影距离，作为弯曲姿态代理 |
| `profile_width_median_mm / max_mm / p90_mm` | 可算且未标记不可测的 K 剖面宽度统计；缺失时只汇总已有剖面，须同时读取可算数量 |
| `width_25pct_mm / 50pct_mm / 75pct_mm` | 另取精确弧长 25/50/75% 局部法向薄带独立算宽度，不是最近 K 站位或宽度插值；路径不可靠时缺失。始终是候选值，邻近剖面的确认不确认这些额外平面 |
| `visible_height_p95_mm` | 整个保留区间 Z 的 P95；仅在地面参考已复核时输出 |
| `relative_height_p95_p05_mm` | 区间全体 Z 的 P95−P05，不依赖地面平移，但不是猪的实际高度 |
| `observed_grid_area_mm2` | `floor(X/grid),floor(Y/grid)` 有点网格数×网格面积；洞不填充，数值依赖网格分辨率 |
| `observed_positive_height_integral_mm3` | 每个有点 XY 格取 Z 中位数，负值截为 0，再乘格面积求和；需复核地面。这是可见高度积分代理，不能当整猪体积 |

宽度为 `Q98(u)−Q02(u)`，减轻少量极端点影响；每片另存 `width_raw_span_mm=max(u)−min(u)` 作对照。它会受采样密度、遮挡、体侧缺失和残余飞点影响，不是真实完整体宽、胸围或横截面积；分位数不替代飞点清理。

端点完整、路径有支撑且全部 K 片可测时，宽度统计的 `reviewed` 才为真；长度需端点复核且相关数值可算。地面高度的 `reviewed` 表示地面参考已复核。面积和积分仍作为候选代理，没有自动验收整个体表的机制。

## 固定剖面序列 T

默认 `values.shape=(32,9)`，通道名与单位写入 NPZ。

| 通道 | 定义 | 单位 |
| --- | --- | --- |
| `width_q02_q98_mm` | 局部可见横向稳健跨度 | mm |
| `height_p95_mm` | 本片 Z 的 P95，需地面复核 | mm |
| `relative_height_p95_mm` | 本片 Z 的 P95 减整个区间 Z 的 P05 | mm |
| `height_gradient` | 相邻两侧高度差/弧长差，端部单侧差分；自身或邻片缺高程、被拒绝时缺失 | mm/mm |
| `transverse_curvature_per_mm` | 横向网格中位数二次拟合的中心带符号曲率，不是整猪解剖曲率 | 1/mm |
| `bulge_mm` | 拟合中心高度减两端拟合高度均值，凸起为正 | mm |
| `point_count` | 薄带实际保留点数，0 可以是真实空带计数 | count |
| `transverse_bin_coverage` | 12 个横向小格中至少含 2 点的格子比例，不是体表可见率或边界完整概率 | ratio |
| `fit_rmse_mm` | 二次曲线对有效横向格中位数的 RMSE，小误差不证明边界完整 | mm |

二次拟合仅在稳健宽度至少 40 mm、12 格中至少 6 格各有 2 点，且有效格横向覆盖至少稳健宽度 70% 时输出。设 `v=(u−宽度中点)/宽度`，拟合 `z=a v²+b v+c`：中心曲率为 `(2a/宽度²)/(1+(b/宽度)²)^(3/2)`，凸起为 `−a/4`。这些是当前可检验的实现定义，不宣称文献已验证了本实现参数。

## 缺失与复核掩码

JSON 用 `null`，CSV 用空单元格，NPZ 用 `NaN`，不会把缺宽度、缺高度填成实测零。三个同形布尔矩阵：

- `valid_mask`：该通道数值可算；`point_count=0` 可以是真实计数，但形状通道可能缺失。
- `usable_mask`：数值可算、站位有中心线支撑、剖面未拒绝，且整个中心线路径支持定长站位、端点未标记截断。待定剖面可能为真，不能当人工确认。
- `reviewed_mask`：在 usable 基础上，当前剖面已确认可测且两端已确认完整。地面未复核时高度通道本来就无效。

中心线有缺口时可保留局部诊断候选，但定长序列的 `usable_mask` 全为假；参考曲线 0–100% 不代表可靠完整体段。截断端点同样禁止直接把部分躯干伸缩成完整输入。`sequence_position_valid` 表示路径有支撑，端点是否人工确认仍须看 `conditions.endpoints`。

每片另存 status、missing_reason、centerline_supported、中心 XY、切向、弧长与比例。点数、覆盖率、拟合误差只作质量代理，不生成虚构置信度，也不把 IR 灰度当幅值/深度置信度。

## 导出与后续使用

| 文件 | 内容 |
| --- | --- |
| 每条 `geometry_features.json` | G、剖面列表、精确分位平面、定义、中心线支撑、参数、条件、警告、输入哈希和坐标参考 |
| 每条 `profile_sequence.csv` | K 行及各通道 valid/usable/reviewed 列 |
| 每条 `profile_sequence.npz` | values、三种掩码、channel_names、channel_units、fraction、arc_position_mm、schema_version；可 `allow_pickle=False` 读取 |
| 根目录 `geometry_features.csv` | 按猪号、采集、模态、相机列出 G、掩码、质量统计、参数、输入版本；未对齐行标 `unaligned` 并留空特征 |

导出用同一模块重新计算，绑定原点云/生成记录哈希、清理摘要和已确认坐标参考；不会导出显示采样的测量值。未保存处理记录也可以计算和批量导出，不强制创建清理操作。`has_features` 只说明导出了文件；原 `measurement_ready` 仍表示旧直线切片复核，不等于新序列验收。

面积、全局高度和积分统计整个保留区间；标记剖面不可测不等于删除点，只有宽度序列汇总跳过该片。如污染影响全局特征，应回到清理或采集筛选。

后续须关联真实称重表；批量表的 `weight_kg` 留空、`weight_status=not_provided`，不虚构标签。按猪个体拆分训练/验证，核对称重与采集时刻，避免同猪不同帧泄漏。iToF 与双目先分别验证；K、厚度、网格应一致或作为明确试验变量。预测价值和特征取舍需真实体重交叉验证，本功能只负责可追溯输入提取。
